### 1. Multi-Step Form Automation with State Persistence
MRO work order updates typically involve 5-7 form fields across 2-3 screens. The extension orchestrates the entire multi-step update as a single transaction — filling all fields in sequence with configurable delays, handling redirect-based navigation, and persisting progress so that if the session is interrupted, it resumes from the last completed step rather than starting over.

### 2. AOG (Aircraft on Ground) Priority Detection
The extension monitors incoming work orders for AOG classification and automatically escalates these to a dedicated priority queue — surfacing them in a floating alert overlay regardless of what screen the user is on. AOG orders bypass the normal queue and trigger an immediate keyboard shortcut for rapid processing.

### 3. Audit-Trail Action Logging
Every automated action is logged to a timestamped local audit trail with the work order ID, action performed, before/after values, and operator session ID. This log can be exported as PDF for regulatory compliance documentation.

### 4. Adaptive Rate-Limiting & Cooldown Circuit Breaker
High-frequency monitoring loops are protected by an automated circuit breaker. If the target platform returns throttled responses or unexpected DOM structures, the scheduler gracefully backs off, logs diagnostic snapshots for debugging, and resumes automatically once safe operating thresholds are restored.
