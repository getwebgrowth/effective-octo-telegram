## Executive Summary

**Tech Copilot** is a specialized floating AI assistant designed for automotive technicians, mechanics, and repair engineers navigating dense OEM vehicle repair portals (ALLDATA, Mitchell 1, Identifix). Instead of switching tabs or manually copying technical diagrams, technicians use Tech Copilot's draggable browser overlay to extract wiring diagrams, interpret diagnostic trouble codes (DTCs), and receive instant step-by-step repair guides directly on top of OEM web manuals.

## The Challenge

1. **Complex OEM Web Portals**: Automotive manual portals rely on nested iframes, protected dynamic DOM elements, and PDF canvas viewers that resist traditional browser scraping.
2. **Contextual Accuracy & Hallucination Prevention**: Automotive repair requires zero hallucination—a wrong wiring pinout or torque specification can damage costly vehicle components.
3. **Monetization & Free Trial Quotas**: The client required a freemium model (e.g. 20 free AI queries per month with automatic monthly reset) and seamless Stripe/ExtensionPay checkout without requiring a heavy custom auth backend.
4. **Draggable, Non-Intrusive UI**: Mechanics need a floating HUD that stays on top of technical manuals without causing page reflows or breaking site layout.

### 1. Isolated Shadow DOM Floating Overlay
To prevent styling conflicts with complex OEM portals (like Bootstrap or Tailwind CSS overrides), the entire assistant HUD is encapsulated inside a custom **Closed Shadow DOM Root**. The HUD features draggable positioning, collapsible states, and zero impact on target site scripts.

### 2. Multi-Model AI Pipeline (OpenAI + Gemini Pro RAG)
Implemented a multi-tier LLM processing engine:
- **Snip & Capture Screen Extractor**: Uses the Chrome Capture API to let mechanics snip electrical schematics or connector pinouts.
- **Gemini Pro Vision RAG**: Analyzes captured wiring diagrams, extracts wire color codes and connector pin tables.
- **OpenAI Streaming Output**: Streams step-by-step diagnostic workflows into the chat UI in real time.

### 3. ExtensionPay Freemium Monetization
Integrated ExtensionPay for automated subscription billing:
- Tracks user usage counts in `chrome.storage.sync`.
- Enforces monthly free-tier quotas with automatic calendar reset.
- Triggers one-click Stripe subscription modals directly from the extension.

### 4. Client-Side Vault & Zero-Leak Credential Hygiene
User API keys and proprietary system prompts are secured inside `chrome.storage.session` and isolated from the host webpage scope. The extension runs strict Content Security Policy (CSP) headers and sandboxed execution contexts, preventing unauthorized third-party scripts from reading session tokens or prompt payloads.
