## What It Does — 6 Core Features

From the live product at [techaicopilot.com](https://www.techaicopilot.com):

### 🔍 AI-Driven TSB & Service Search
Surfaces relevant Technical Service Bulletins and service information, plus hard-to-find or outdated technical insights that are often missed in standard searches.

### 🚗 VIN Decoding
Enter a 17-character VIN and attach the decoded vehicle info (make, model, year, trim) to the chat session — so every AI answer is grounded in the right vehicle.

### 📋 Diagnostic Pattern Matching
Connects symptoms to likely causes using common issues and real-world failure patterns — no starting from scratch with every new vehicle.

### 📸 Screenshot & Full-Page Capture
Snip a section or capture an entire scrolling page from any OEM reference system, then hand it straight to the AI for context. Works across wiring diagrams, service manuals, and connector pinouts.

### 🔎 Local OCR Text Extraction
Pulls text out of any screenshot instantly using **Tesseract.js** — running entirely on-device. No image ever leaves the browser for OCR processing.

### 🎙️ Voice Input, Hands-Free
Speak a question and watch it transcribe live into the chat input — no typing required when working in the bay.

### 1. Side Panel Architecture (Manifest V3)
Built as a Chrome Side Panel extension (MV3) rather than a floating overlay — this means it docks natively alongside any OEM manual or repair system without causing page reflows or CSS conflicts.

### 2. Multi-Model AI Pipeline (OpenAI + Gemini Pro RAG)
- **Screenshot Capture**: Chrome Capture API for snipping wiring diagrams and connector pinouts.
- **Local OCR (Tesseract.js)**: Text runs entirely on-device — no image is sent to an external OCR service.
- **Gemini Pro Vision RAG**: Analyzes captured wiring diagrams, extracts wire color codes and connector pin tables.
- **OpenAI GPT-4o Streaming (SSE)**: Streams step-by-step diagnostic workflows into the chat UI in real time.

### 3. ExtensionPay Freemium Monetization ($5.99/mo Pro)
- Tracks usage counts in `chrome.storage.sync`
- Free tier with limited actions — upgrade to Pro for unlimited diagnostics
- One-click Stripe subscription modals via ExtensionPay
- Zero custom auth backend required

### 4. Privacy-First Design
- OCR runs locally with Tesseract.js — screenshots never leave the browser
- Conversations stored locally in extension storage — not in the cloud
- No login required to start diagnosing
- Minimal permissions model compliant with Chrome Web Store Single Purpose policy
