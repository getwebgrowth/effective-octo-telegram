## What Is No-Code Web Scraper?

**No-Code Web Scraper** is a visual point-and-click data extraction Chrome extension designed for non-technical users — growth marketers, lead researchers, sales teams, e-commerce analysts, and data journalists — who need to extract structured data from websites without writing any code.

Users simply hover over elements on any webpage, click to select them, and the extension automatically generates smart CSS selectors, handles multi-page pagination, and exports the collected data directly to **Google Sheets**, **Airtable**, or **CSV** download.

- **Platform**: [nocodewebscraper.com](https://nocodewebscraper.com/)
- **No-code**: Zero programming knowledge required
- **Deep scraping**: Works on modern web apps with Shadow DOM and Web Components

## How It Works (Step by Step)

1. **Install** the extension and navigate to any website
2. **Click "Start Selecting"** — a hover overlay activates on the page
3. **Hover over any element** (product card, table row, contact entry) — it highlights automatically
4. **Click to confirm selection** — the extension captures that element's CSS selector path
5. **Click similar elements** on the page — the extension generalizes the selector pattern to match all similar items
6. **Configure pagination** (optional) — point and click the "Next Page" button to enable multi-page crawling
7. **Click "Extract Data"** — all matching elements across all pages are collected and shown in a preview
8. **Export** — one click to push data to Google Sheets, download CSV, or sync to Airtable

### 1. Shadow DOM Recursive Traversal Engine
Modern web applications (LinkedIn, Salesforce, Shopify admin, Webflow sites) use **Web Components with Shadow DOM** — isolated DOM trees that are invisible to `document.querySelector`. Standard scrapers completely miss this data.

No-Code Web Scraper includes a custom recursive **Shadow DOM traversal algorithm**:
```javascript
function queryShadowAll(root, selector) {
  let results = [...root.querySelectorAll(selector)];
  root.querySelectorAll('*').forEach(el => {
    if (el.shadowRoot) {
      results = results.concat(queryShadowAll(el.shadowRoot, selector));
    }
  });
  return results;
}
```
This allows extraction from deeply nested Web Component trees that would be completely invisible to conventional scrapers.

### 2. Resilient Selector Generator
When a user clicks two or three sample elements from a list (e.g., three product cards), the engine analyzes the DOM paths between them to generate a **generalized CSS selector** that matches all similar elements — even if they have dynamic IDs or obfuscated class names.

The selector generator evaluates multiple candidate strategies (nth-child, attribute selectors, ARIA roles) and picks the most stable one that will survive minor site redesigns.

### 3. Multi-Page Pagination Crawler
Users simply click the "Next Page" button on a paginated site to register its selector. The extension's pagination state machine then:
1. Extracts all data from the current page
2. Clicks "Next Page" programmatically
3. Waits for the new page DOM to stabilize (via MutationObserver settlement detection)
4. Extracts data from the new page
5. Repeats until the "Next Page" button disappears or a user-configured page limit is reached

### 4. Google Sheets & Airtable Export
Extracted data is batch-written to Google Sheets using the Sheets API v4 `values.append` endpoint with OAuth2 via `chrome.identity`. Airtable export uses the Airtable REST API with personal access token auth. Both export modes map scraped columns to user-configured destination fields.
