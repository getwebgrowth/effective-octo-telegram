### 1. Platform-Priority Order Routing
Different marketplace orders have different SLA requirements. Amazon MFN orders have a configurable handling time (24-48 hours) with metrics tracked by Amazon. eBay and Etsy have buyer expectations. The extension prioritizes the fulfillment queue based on platform SLA deadlines — always ensuring the most time-critical orders process first regardless of channel.

### 2. 3PL Warehouse Routing Rules
For sellers using multiple warehouses or third-party logistics (3PL) providers, the extension applies configurable routing rules — sending specific product categories to specific warehouses based on product tags, weight, or origin location. Pick lists are generated per warehouse in the warehouse's layout sequence (aisle → shelf → bin order) to minimize walking distance.

### 3. Batch Tracking Push with Rollback
After processing a fulfillment batch, tracking numbers are pushed to all originating platforms simultaneously via parallel API calls. If any platform's tracking submission fails (API error, network timeout), the extension rolls back the batch — preventing a state where some platforms show "shipped" while others still show "pending" for the same orders.

### 4. Cross-Platform Schema Normalization & Error Logging
Data formats vary widely between external platforms. The engine maps diverse schema variations into standardized strongly-typed data contracts, validating field formats before dispatch and streaming diagnostic event logs for rapid issue resolution.
