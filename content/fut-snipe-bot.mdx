## 11 Core Features & Technical Capabilities

EliteFutBot was engineered from the ground up to solve every pain point of manual transfer market trading — from reaction latency to ban prevention and automated profit tracking:

### 01 // Auto Snipe (Sub-Second Market Execution)
Scans live transfer market listings and auto-purchases players that match your price and rating criteria at sub-250ms speeds — drastically faster than manual human clicking, securing underpriced player cards before competing buyers or bots can react.

### 02 // Auto List & Auto Sell (Automated Flip Cycles)
Automatically relists sniped players on the transfer market at your designated target sell price range, or auto-sells them outright at current market value. Eliminates the need to babysit your club inventory after every successful flip.

### 03 // Smart Filters (Target Criteria & Safety Limits)
Configurable search bounds allow users to specify minimum and maximum buy-now prices, bid limits, player card ratings, chemistry styles, card tiers (Gold Rare, Special, TOTW), and a hard purchase cap per search session to prevent accidental overspending.

### 04 // Futbin Price Reference (Real-Time Market Valuation)
Pulls real-time pricing data directly from the **Futbin API** for both console (PlayStation / Xbox) and PC markets. Ensures you are sniping against verified live market prices and calculated profit margins rather than static guesswork.

### 05 // Anti-Detection Engine (Configurable Action Delays)
Configurable, humanized action delays between search queries and button clicks prevent repetitive cadence detection. Distributes requests across randomized temporal intervals, keeping account activity indistinguishable from a regular human player.

### 06 // Humanization++ (Physics-Based Mouse & Click Simulation)
Engineered in direct response to community reports of automation-related market bans. Humanization++ goes far beyond simple timer delays: it generates natural Bezier curve mouse trajectories, randomized click coordinate offsets within button bounding boxes, and dynamic dwell times, interacting with the page DOM exactly like an organic user.

### 07 // Native Side Panel UI (Unobtrusive Game Controls)
Runs entirely within Google Chrome's native Side Panel API (`chrome.sidePanel`). Your configuration controls, search modes (Safe, Caution, Risky), and live logs sit comfortably alongside the EA FC Web App without obscuring game elements, pack animations, or club menus.

### 08 // Centralized Web Dashboard (License & Preset Management)
Manage your subscription license, device activations, sniping presets, and account preferences from a unified cloud web dashboard — eliminating the need to reconfigure complex settings through browser extension popups.

### 09 // Free Discord Support & Community Alerts
Includes direct access to the official EliteFutBot Discord community. Users receive free onboarding support, shared high-margin sniping filters, market trend discussions, and real-time alerts whenever EA updates the Web App.

### 10 // Live Stats Sync (Real-Time Session Telemetry)
Real-time HUD counter displays total cards purchased, accumulated coin profit, current search loop latency, session running time, and total snipes logged today. Gives traders immediate transparency into session profitability.

### 11 // Secure Login (EliteFutBot Cloud Authentication)
Frictionless, one-time authentication through the extension's built-in login workflow, backed by the secure **EliteFutBot Cloud API** with tokenized session validation and encrypted license verification.

### 1. Dual-World Script Injection Architecture
Standard Manifest V3 extensions execute within an Isolated World where page-native JavaScript objects, internal state, and WebSocket streams are unreachable. Pasindu engineered a **dual-layer execution bridge**:
- **Main World Injector**: Directly taps active session tokens, hooks transfer market WebSocket streams, and monitors auction listings as raw data before DOM elements are rendered.
- **Isolated World Side Panel**: Operates inside Chrome's native Side Panel API, providing a secure, high-performance React user interface that communicates with the Main World via structured custom event bridges.

### 2. Humanization++ Anti-Ban Mathematics
To beat EA FC's server-side machine learning heuristics, Humanization++ calculates non-linear mouse paths using cubic Bezier curves:

$$B(t) = (1-t)^3 P_0 + 3(1-t)^2 t P_1 + 3(1-t) t^2 P_2 + t^3 P_3$$

Clicks are offset dynamically within element bounding boxes with Gaussian random noise, ensuring no two clicks ever strike the exact same pixel coordinate.

### 3. Adaptive RPM Rate Throttling
The engine dynamically tracks Requests Per Minute (RPM) and monitors HTTP response status headers. If rate-limit indicators or network latency spikes occur, the bot initiates an exponential backoff cooldown without crashing the session or alerting anti-bot tripwires.
