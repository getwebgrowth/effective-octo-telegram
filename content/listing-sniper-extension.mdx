### 1. SP-API Competitive Pricing Integration
The extension uses Amazon's Selling Partner API (SP-API) Competitive Pricing endpoint to get real-time Buy Box pricing data — the same data Amazon uses internally. This provides the exact current Buy Box winner, their price, fulfillment type (FBA/FBM), and all competing offers with their prices and seller metrics.

### 2. 90-Second Monitoring with Chrome Alarms Precision
Chrome Alarms have a minimum resolution of 1 minute. The extension uses a staggered alarm schedule (Alarm A at :00, Alarm B at :30) to achieve effective 90-second monitoring cycles — monitoring 200 ASINs across two alternating batches without exceeding SP-API rate limits.

### 3. Automated Repricing via SP-API
When a Buy Box opportunity is detected and the seller's current price is within the configured guardrails (min margin price and max price), the extension can automatically update the listing price via SP-API's `putListingsItem` endpoint — capturing the Buy Box opportunity within seconds of detection without manual intervention.

### 4. Adaptive Rate-Limiting & Cooldown Circuit Breaker
High-frequency monitoring loops are protected by an automated circuit breaker. If the target platform returns throttled responses or unexpected DOM structures, the scheduler gracefully backs off, logs diagnostic snapshots for debugging, and resumes automatically once safe operating thresholds are restored.

When multiple sellers offer the same product, Amazon selects one seller to feature in the Buy Box — and that seller gets ~82% of all sales on that listing. Amazon's algorithm rotates the Buy Box based on price competitiveness, fulfillment method (FBA vs. FBM), seller rating, and shipping speed. Winning the Buy Box is critical to Amazon revenue." />
