### 1. Hunter.io Email Discovery Integration
For each scraped lead (first name + last name + company domain), the extension calls Hunter.io's Domain Search API to find verified email addresses associated with the company domain — returning emails with confidence scores. Low-confidence emails are discarded to protect sender reputation.

### 2. GPT-4o Hyper-Personalized Opening Lines
The 12% reply rate was driven by genuinely personalized first lines. For each lead, GPT-4o analyzes the prospect's LinkedIn headline, recent activity, and company context to generate a unique, conversational opening sentence that references something specific about them — rather than a generic "I came across your profile" opener.

### 3. Chrome Alarms Email Sequence Executor
Follow-up emails are scheduled via `chrome.alarms` — the extension automatically sends Day 3 and Day 7 follow-up emails from the Gmail API if no reply is detected. Reply detection works by monitoring Gmail inbox labels using the Gmail API — removing the prospect from the sequence as soon as a reply arrives.

### 4. Adaptive Rate-Limiting & Cooldown Circuit Breaker
High-frequency monitoring loops are protected by an automated circuit breaker. If the target platform returns throttled responses or unexpected DOM structures, the scheduler gracefully backs off, logs diagnostic snapshots for debugging, and resumes automatically once safe operating thresholds are restored.
