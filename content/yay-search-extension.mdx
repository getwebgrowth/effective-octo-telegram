### 1. GPT-4o-mini Boolean Query Optimization
The extension converts the analyst's natural language question into a precision Boolean search query. For example: "What are the revenue figures for Stripe in 2024?" becomes `("Stripe" AND "revenue" OR "ARR") AND "2024" site:techcrunch.com OR site:bloomberg.com OR filetype:pdf`. This dramatically improves result precision without requiring the user to know Boolean search operators.

### 2. Multi-Engine Result Aggregation
The extension opens results from multiple search engines in coordinated background tabs, extracts search result snippets from each engine's DOM (using engine-specific extraction logic), deduplicates URLs that appear in multiple engines, and presents a unified ranked list — showing which engines returned which results and surfacing results that appear across multiple engines as more credible.

### 3. Domain-Specific Search Mode Templates
The extension includes pre-configured search mode templates for specific research domains: Legal research (Justia, CourtListener, PACER sources), Academic research (Google Scholar, Semantic Scholar, ArXiv), Competitive intelligence (Crunchbase, LinkedIn, news sources), and Technical documentation (GitHub, MDN, Stack Overflow). Each mode applies domain-appropriate query operators and source filters automatically.

### 4. Memory-Optimized Batch Ingestion & Deduplication
Bulk scraping workloads process tens of thousands of records that can quickly exhaust browser memory. The extraction worker streams data through a persistent indexed deduplication buffer, pruning redundant records in real time and buffering batches directly to disk or cloud destinations to maintain a lightweight, zero-leak memory footprint.
