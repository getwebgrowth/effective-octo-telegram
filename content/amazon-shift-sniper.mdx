## Executive Summary

**Amazon Shift Sniper** is a high-speed, automated workforce monitoring and booking Chrome extension built for Amazon recruitment and shift scheduling portals. In high-demand labor markets, premium warehouse shifts and delivery slots are released unpredictably and disappear in milliseconds.

This extension provides continuous background slot polling, instantly identifies released shifts, and executes automated booking with sub-second latency while intelligently preventing CloudFront rate-limit bans.

- **Architecture**: Manifest V3 Service Worker + Offscreen Keepalive + Dual-World Script Injection.

## The Challenge

1. **Sub-Second Competition**: Shifts disappear within 500ms of release to competing automated scripts.
2. **CloudFront 403 Rate Limits**: High-frequency polling on Amazon hiring portals triggers CloudFront and AWS WAF rate-limiting rules, causing temporary IP blacklists (HTTP 403).
3. **Session Token Desynchronization**: Standard extension fetch calls fail due to cross-origin CORS barriers and missing dynamic CSRF session tokens.
4. **Manifest V3 Background Inactivity**: Chrome terminates MV3 background service workers after 30 seconds of idle time, killing continuous monitoring tasks.

### 1. Dual-Layer Script Injection (Main World + Isolated World)
- **Main World Script**: Injected directly into the portal's DOM runtime to read internal authentication tokens, headers, and dynamic session cookies. This bypasses standard CORS and authentication blocks by making API calls appear 100% native to the portal.
- **Isolated World HUD**: Renders a glassmorphic floating control panel displaying real-time metrics: polling speed, monitored locations, active shifts found, and cooldown status.

### 2. CloudFront 403 Auto-Cooldown Bridge
To survive 24/7 background operation:
- The extension intercepts HTTP response status codes.
- When an AWS WAF / CloudFront 403 error is detected, the engine enters an **automatic 60-second cooldown mode** with randomized jitter intervals.
- Once the rate-limiting window clears, polling resumes seamlessly with zero manual browser refreshing.

### 3. Persistent 24/7 Service Worker Keepalive
Utilizes the **Chrome Offscreen Document API** to maintain active timer loops and WebSocket connectivity, overcoming the 30-second Manifest V3 service worker termination limitation.

### 4. Adaptive Rate-Limiting & Cooldown Circuit Breaker
High-frequency monitoring loops are protected by an automated circuit breaker. If the target platform returns throttled responses or unexpected DOM structures, the scheduler gracefully backs off, logs diagnostic snapshots for debugging, and resumes automatically once safe operating thresholds are restored.
